Smart Computer Repair System

A computer repair and management application designed to simplify customer management, computer diagnostics and repair tracking.

Python | Tkinter | SQLite

Project Overview

The Mwila Smart Computer Repair System is a desktop application developed to help computer technicians manage repair operations efficiently. It stores customer information, records computer problems, tracks repair progress and generates repair reports.

System Features

Customer Registration

Register and manage customer details and contact information.

New Repair Records

Record devices, reported problems, diagnosis and repair costs.

Repair Tracking

Monitor repair progress and update repair statuses.

Computer Diagnostics

Record technical findings and diagnostic information.

Repair Reports

View repair statistics and total repair values.

CSV Export

Export repair records into CSV files for further analysis.

Technologies Used

Python – Application programming
Tkinter – Graphical user interface
SQLite – Database management
